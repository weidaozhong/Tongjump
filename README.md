# 毛球向上跳 · Maoqiu Jump

一个手绘涂鸦风格的「向上跳」网页小游戏：操控圆滚滚的毛球，踩着一格格台阶不断往上跳，跳得越高分越高。
电脑、手机浏览器都能玩。

## 特色
- **5 只毛球皮肤**：棕、粉、紫、蓝、白，开局自由选择。
- **可换主题音乐**：每套主题有专属配色与背景音乐，一键切换；默认「经典」主题为方格纸手绘风 + 轻快纯音乐。
- **双端操控**：电脑用方向键 / A·D；手机左右倾斜或按住屏幕左右半边。
- **丰富机制**：移动台阶、踩碎台阶、弹簧超级弹跳、喷气背包短暂飞行。
- **结算与分享**：手绘"高度勋章"结算卡，破纪录有提示，可一键分享给好友一起比高度。
- **可安装**：支持 PWA「添加到主屏幕」，像 App 一样全屏运行。

## 玩法
- 毛球会自动起跳，踩到台阶就往上弹；分数 = 跳到的高度，最高分自动记录。
- 台阶：普通 / 左右移动 / 踩一下先弹再碎（一次性）。
- 道具：弹簧（超级弹高）、喷气背包（短暂飞行）。
- 掉出屏幕底部即结束。
