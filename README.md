# 毛球向上跳 · Maoqiu Jump

一个手绘涂鸦风格的「向上跳」网页小游戏：操控圆滚滚的毛球，踩着一格格台阶不断往上跳，跳得越高分越高。
电脑、手机浏览器都能玩。

## 特色
- **5 只毛球皮肤**：棕、粉、紫、蓝、白，开局自由选择；四肢与耳角统一米白，身体配色区分。
- **可换主题音乐**：每套主题有专属配色与背景音乐，一键切换，并带静音开关；默认「经典」主题为方格纸手绘风 + 轻快纯音乐。暗色主题下毛球带细描边，任何背景都清晰。
- **双端操控**：电脑用方向键 / A·D；手机为虚拟摇杆——按住屏幕左右滑动，滑得越远跑得越快、松手减速。
- **丰富机制**：移动台阶、踩碎台阶（踩一下先弹再碎）、弹簧超级弹跳、喷气背包短暂飞行。
- **结算与分享**：手绘"高度勋章"结算卡，分数滚动、破纪录提示；可一键分享给好友（系统分享 / 二维码 / 复制链接 / QQ）一起比高度。
- **个人最高分本地保存**：每位玩家的最高分保存在各自浏览器本地，持续记录、破纪录自动刷新。
- **细节**：桌面鼠标静止自动隐藏；暂停时音乐继续、游戏结束音乐停止、再来一次从头播放。
- **可安装**：支持 PWA「添加到主屏幕」，像 App 一样全屏运行。

## 玩法
- 毛球会自动起跳，踩到台阶就往上弹；分数 = 跳到的高度，最高分自动记录。
- 台阶：普通 / 左右移动 / 踩一下先弹再碎（一次性）。
- 道具：弹簧（超级弹高）、喷气背包（短暂飞行）。
- 操控：电脑方向键 / A·D；手机按住屏幕左右滑动（虚拟摇杆）。
- 掉出屏幕底部即结束。
