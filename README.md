# 毛球向上跳 · Maoqiu Jump

一个手绘涂鸦风格的「向上跳」网页小游戏：操控圆滚滚的毛球，踩着一格格台阶不断往上跳，跳得越高分越高。
电脑、手机浏览器都能玩。

## 特色

- **5 只毛球皮肤**：棕、粉、紫、蓝、白，开局自由选择；四肢与耳角统一米白，身体配色区分。两层独立选择——皮肤与主题互不影响。
- **每个主题独立画风**：主题不只是换配色，连背景纹理、台阶造型、道具样式都各不相同，并贴合歌曲氛围。
  - 经典：暖纸方格底 + 圆角台阶（原版风格）。
  - 暗色主题（如 Even in the Dark）：近黑暗角 + 上飘余烬，锐利石板台阶 + 发光边，道具走暗黑发光风。
  - 明亮主题（如 Fearless）：浅底 + 漂浮圆斑，饱满胶囊台阶 + 高光，道具走糖果高光风。
- **可换主题音乐**：每套主题有专属背景音乐，一键切换并带静音开关；经典主题为方格纸手绘风 + 代码合成的轻快纯音乐。暗色主题下毛球带细描边，任何背景都清晰。
- **生命值系统**：顶部居中 3 颗心。掉到底部不再直接结束，而是扣一颗心、在台阶上复活、分数继续累计；三颗心全部失去才结束。
- **丰富道具**：喷气背包（短暂飞行）、弹簧（超级弹跳）、回血心（补一颗心）、护盾（抵挡一次掉血）、磁铁（吸附生效后看到的第一个道具）。道具自动间隔出现、绝不连续重复同一种。
- **双端操控**：电脑用方向键 / A·D；手机为虚拟摇杆——按住屏幕左右滑动，滑得越远跑得越快、松手减速，灵敏度经过调校便于精确落点。
- **结算与分享**：手绘“高度勋章”结算卡，分数滚动、破纪录提示，结算时背景回到干净的纯主题画面；可一键分享给好友（系统分享 / 二维码 / 复制链接 / QQ）一起比高度。
- **个人最高分本地保存**：每位玩家的最高分保存在各自浏览器本地，持续记录、破纪录自动刷新。
- **细节**：桌面鼠标静止 1.5 秒自动隐藏、移动再现；暂停时音乐保留进度续播、游戏结束音乐停止、再来一次从头播放；手机端音频在首次触摸时解锁，确保各主题音乐都能播放。
- **可安装**：支持 PWA「添加到主屏幕」，像 App 一样全屏运行。

## 玩法

- 毛球会自动起跳，踩到台阶就往上弹；分数 = 跳到的高度，最高分自动记录。
- 台阶：普通 / 左右移动 / 踩一下先弹再碎（一次性）。
- 道具：喷气背包（飞行）、弹簧（弹高）、回血心（补血）、护盾（免一次掉血）、磁铁（吸道具）。
- 生命值：顶部 3 颗心，掉落扣一颗并在台阶复活续分，心掉光才结束。
- 操控：电脑方向键 / A·D；手机按住屏幕左右滑动（虚拟摇杆）。
